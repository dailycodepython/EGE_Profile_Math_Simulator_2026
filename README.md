# 🚀 Interactive Simulator for EGE Profile Mathematics in Google Colab

Welcome! This repository is designed for high school graduates preparing for the **Unified State Exam (EGE) in advanced profile mathematics** who want to combine exam preparation with modern programming capabilities.

Instead of boring paper test books, this project offers an **interactive Python notebook** that transforms abstract mathematical formulas into tangible, readable algorithms.


---

## 🛠 How to Use This Project / Как пользоваться проектом?

1. **Open in Google Colab:** Click on the `.ipynb` file in this repository and open it via Google Colab.
2. **Run the Cells:** Execute the Python code cells sequentially to visualize math problems.
3. **Practice:** Solve tasks interactively and test your skills using algorithms.

---

### 📈 Features / Преимущества:
* **Algorithm-Driven Math:** Understand the logic behind tough profile math problems.
* **Interactive Code:** Modify variables in real-time to see how equations change.
* **Google Colab Ready:** No installation required, works straight from your browser.

  


# 🚀 Интерактивный тренажер-симулятор для подготовки к ЕГЭ по профильной математике в Google Colab

Добро пожаловать! Этот репозиторий создан для выпускников 11 классов, которые готовятся к сдаче **ЕГЭ по профильной математике** и хотят совместить подготовку с возможностями современного программирования.

Вместо скучных бумажных сборников здесь собран интерактивный Python-ноутбук, который превращает абстрактные математические формулы в осязаемые алгоритмы.

## 📥 Как пользоваться проектом?

Вы можете изучать код прямо здесь, на GitHub, но для полноценной работы лучше запустить его в интерактивной среде:

1. Скачайте файл `EGE_Pro_Math_Full.ipynb` из этого репозитория.
2. Откройте [Google Colab](https://google.com) под своим аккаунтом.
3. Нажмите `Файл` -> `Загрузить блокнот` и выберите скачанный файл.
4. Поочередно запускайте ячейки (нажимая `Ctrl + Enter` или иконку Play), изучайте теорию и крутите интерактивные графики!

---

## 🛠 Что внутри блокнота?

Материал разбит строго по структуре КИМ Профильного ЕГЭ и кодификатору ФИПИ. Для **каждого из 19 заданий** внутри реализовано 4 блока:

1. **📋 Пошаговая инструкция:** Краткая, емкая теория «без воды», формулы-выручалочки и алгоритм действий на реальном экзамене.
2. **💻 Интерактивный код (Python):** 
   * Автоматические вычисления с помощью библиотеки символьной математики `SymPy` (с учетом ОДЗ и отсеиванием ложных корней).
   * Графические 2D/3D симуляторы (для визуализации геометрических задач, параметров и графиков функций).
   * Построение реальных финансовых таблиц для кредитов и вкладов.
3. **📝 Задачи для тренировки:** Несколько аналогичных прототипов задач с ответами для мгновенной самопроверки.
4. **📚 Литература:** Ссылки на конкретные главы и параграфы классических школьных учебников (Атанасян, Погорелов, Алимов, Макарычев), чтобы быстро подтянуть базовую теорию.

## 📊 Краткое содержание интерактивных модулей

* **Задания 1, 16 (Планиметрия):** Скрипты для расчета тригонометрии в треугольниках и точного построения геометрических чертежей окружностей.
* **Задание 2 (Векторы):** Координатный анализатор векторов с отрисовкой векторов-стрелок на координатной сетке.
* **Задания 3, 17 (Стереометрия):** 3D-моделирование объемных тел (призм, цилиндров), расчет углов между скрещивающимися прямыми векторным методом.
* **Задания 4, 5 (Теория вероятностей):** Симуляторы случайных событий методом Монте-Карло и визуализация пересечения событий через круги Эйлера-Венна.
* **Задания 6, 7 (Уравнения и Выражения):** Символьные вычисления точных корней логарифмических и тригонометрических конструкций.
* **Задания 8, 12 (Математический анализ):** Визуализаторы геометрического смысла производной и автоматический поиск экстремумов на отрезке.
* **Задания 9, 10 (Физические и текстовые задачи):** Автоматические решатели систем уравнений, задач на движение по воде и работу.
* **Задание 11 (Графики функций):** Скрипт, восстанавливающий формулу параболы или гиперболы по точкам с картинки.
* **Задание 14 (Неравенства):** Компьютерный метод интервалов с графической подсветкой областей решений.
* **Задание 15 (Финансовая математика):** Генератор идеальных графиков платежей для дифференцированных и аннуитетных кредитов.
* **Задание 18 (Параметры):** Интерактивный графический сканер плоскости `(x; a)` с ползунками для ручного управления параметром.
* **Задание 19 (Свойства чисел):** Брутфорс-алгоритм для быстрого подбора числовых комбинаций и доказательства математических оценок.
